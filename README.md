Полноценный, современный и реалистичный интернет-магазин, вдохновлённый дизайном и клиентским опытом популярного маркетплейса Узбекистана — **Uzum Market**. 

Проект полностью реализован на чистом стеке **Vanilla HTML5, CSS3 и JavaScript (ES6+)** без использования сторонних фреймворков и серверной части. Работает локально в любом браузере и мгновенно публикуется на **GitHub Pages**.

---

## ✨ Ключевые возможности

### 🎨 Дизайн и интерфейс
- **Фирменная палитра Uzum Market**: глубокий фиолетовый `#7000FF`, контрастный `#5B00D6`, светлый фон `#F4F4F7`, тёмный текст `#1F2026`.
- **Поддержка Тёмной и Светлой темы (Dark/Light mode)** с сохранением выбора в `localStorage`.
- **Переключение языков**: поддержка **Русского** и **O'zbekcha** (узбекского на латинице).
- **Плавные анимации и эффекты**: приподнимание карточек при наведении, масштабирование изображений, мягкие тени и всплывающие Toast-уведомления.
- **Полная адаптивность**: идеально отображается на мониторах, ноутбуках, планшетах и смартфонах (с нижней панелью мобильной навигации).

### 📦 Каталог товаров (55+ позиций)
- Разделение по **13 популярным категориям**:
  * Смартфоны, Ноутбуки, Телевизоры, Наушники, Смарт-часы
  * Одежда, Обувь, Парфюмерия, Косметика
  * Мебель, Бытовая техника, Игрушки, Спортивные товары
- Каждый товар содержит: качественные фотографии, реальное название, цену со скидкой, рейтинг со звездами, число отзывов, расчет ежемесячной рассрочки **Uzum Nasiya**, детальное описание и таблицу технических характеристик.

### 🔍 Поиск, Фильтры и Сортировка
- **Живой поиск (Real-time Search)**: выпадающий список результатов с миниатюрами и ценами прямо во время ввода без перезагрузки страницы.
- **Фильтрация**:
  - По категориям (кнопки-таблетки + боковой сайдбар).
  - По диапазону цен («от» и «до»).
  - «Только со скидкой».
  - По рейтингу покупателей (4.5+, 4.8+).
- **Сортировка**: по популярности, по возрастанию/убыванию цены, по рейтингу, по величине скидки.
- **Интерактивные бейджи активных фильтров** с быстрым сбросом.

### 🛒 Корзина и Оформление заказа
- **Выдвижная боковая корзина (Slide-over Cart Drawer)** с анимацией.
- **Индикатор бесплатной доставки**: наглядный прогресс-бар с подсказкой суммы, необходимой до бесплатной доставки курьером.
- Управление количеством товаров `[-] Qty [+]` и удаление в один клик.
- **Система промокодов**: введите промокод `UZUM10` для получения скидки 10%.
- **Сохранение в localStorage**: корзина не сбрасывается при обновлении страницы.
- **Оформление заказа**:
  - Выбор доставки: курьером до двери или самовывоз из пунктов выдачи Uzum (ПВЗ).
  - Способы оплаты: при получении (наличные/карта), онлайн картами Uzcard/Humo/Visa, в рассрочку Uzum Nasiya.
  - Демонстрационное окно с сгенерированным номером заказа (`UZ-XXXXX`) и квитанцией.

### 💖 Избранное (Wishlist)
- Добавление и удаление товаров в 1 клик через сердечко на карточке.
- Индикатор количества на иконке в шапке и в мобильном меню.
- Отдельное модальное окно для просмотра всех сохраненных товаров.

### ⚡ Интерактивные секции
- **Главный слайдер**: автоматическая смена баннеров каждые 5 секунд, ручные стрелки, индикаторы-точки и пауза при наведении.
- **Скидки дня**: блок с **живым таймером обратного отсчета** (24-часовой цикл до полуночи).
- **Детальное модальное окно товара**: фотогалерея с переключением миниатюр, интерактивный калькулятор рассрочки (на 3, 6 или 12 месяцев), выбор количества, вкладки «Описание» и «Характеристики», кнопка «Купить сейчас».
- **Мега-меню «Каталог»**: разворачивающееся меню категорий и подкатегорий.
- **Выбор города**: 12 крупнейших городов Узбекистана (Ташкент, Самарканд, Бухара и др.).
- **Авторизация Uzum ID**: демонстрационный вход по номеру телефона с кодом из SMS.

## 🚀 Быстрый запуск

### Вариант 1: Локально на компьютере
Просто откройте файл `index.html` в любом браузере (двойной клик по файлу). Никаких серверов, Node.js или дополнительных установок не требуется!

### Вариант 2: Публикация на GitHub Pages (Бесплатный хостинг)
1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `uzum-market`).
2. Загрузите файлы проекта в ветку `main`.
3. Перейдите в **Settings** репозитория ➔ вкладка **Pages**.
4. В секции **Build and deployment** выберите источник:
   - Branch: `main`
   - Folder: `/ (root)`
5. Нажмите **Save**. Через 1–2 минуты ваш сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/uzum-market/`

## 🛠️ Стек технологий
- **HTML5**: Семантическая доступная разметка (BEM-подобные классы).
- **CSS3**: CSS Custom Properties (переменные темы), Grid Layout, Flexbox, Keyframe-анимации, медиазапросы.
- **JavaScript (Vanilla ES6+)**: Модульная организация без внешних зависимостей.
- **Font Awesome 6**: Набор современных иконок через CDN.
- **Google Fonts (Inter)**: Чистая коммерческая типографика.
- **LocalStorage API**: Хранение корзины, избранного, города, языка и темы.
